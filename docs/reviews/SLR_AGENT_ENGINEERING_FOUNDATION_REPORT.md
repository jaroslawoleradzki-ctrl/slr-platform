## 5. Agents implemented

| Agent | Model | Mode | Key permissions |
|---|---|---|---|
| `slr-architect` | `opencode/nemotron-3-ultra-free` | all | read-only; no edit; read-only shell |
| `slr-developer` | `opencode-go/muse-spark-1.3-contributor` | all | source edits; sensitive paths ask; deploy denied |
| `slr-qa` | `opencode/nemotron-3.5-lightning-free` | all | read-only; test/static-analysis shell only |
| `slr-research-reviewer` | `opencode/nemotron-3-ultra-free` | all | read-only; read-only DB and tests |
| `slr-release-engineer` | `opencode/nemotron-3.5-lightning-free` | all | release metadata edits; release/deploy actions ask |

All five deny nested subagents. Read-only agents deny `edit` and have no later
edit allow rule. The release engineer requires approval for `git push*`,
`git tag*`, `gh release*`, and `scripts/deploy_ai_node.sh*`; force-push,
`reset --hard`, `clean`, `stash`, and `rm -rf` are denied.
