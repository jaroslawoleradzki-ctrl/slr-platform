# SLR Platform v0.7.9

**Release date:** 2026-10-31
**Base version:** v0.7.8
**Deployment:** Not performed as part of this change

## Summary

- Includes the approved duplicate-read and first-load fix merged to
  `development` as commit `78452416cbd50b2750afdad1494078919581b294`.
- Adds a manual HomeLab backup script for the existing `slr-platform-v078`
  stack. It backs up the live SQLite database using SQLite Online Backup API,
  copies Compose and `.env` configuration with permissions preserved, and
  verifies the copied database.
- Synchronizes the application version to `0.7.9` in the root version file,
  Python package metadata, and frontend package metadata and lockfile.

No application workflow logic or database schema changes are included in this
version bump and backup utility. No production data or HomeLab configuration was
changed. See [the HomeLab backup runbook](../runbooks/HOMELAB_BACKUP.md) for
manual use.
