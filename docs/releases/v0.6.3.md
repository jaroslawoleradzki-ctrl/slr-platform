# SLR Platform v0.6.3 — Semantic Scholar Field Compatibility Fix

SLR Platform v0.6.3 is a focused hotfix for Semantic Scholar live search.

## Fixed

- Removed the unsupported `language` field from requests to Semantic Scholar's Graph API relevance search endpoint (`GET /graph/v1/paper/search`).
- Semantic Scholar publications now leave `language` unset when the endpoint provides no language metadata; the platform does not infer or fabricate it.
- Retained the v0.6.2 provider-specific plain-text query rendering unchanged.
- Added regression coverage for the exact supported request field contract and for excluding `language`.

## Compatibility and scope

- OpenAlex and Crossref are unchanged.
- No database schema change or migration is required.
- No AI/LLM functionality is added.
