# SLR Platform v0.6.1 — Stage 9 Research Exports & PRISMA 2020 Flow Completion

## Highlights

### Phase 9.8 / Stage 9 — Comprehensive Research Exports

- **Seven Research Export Formats**: Complete implementation and unlocking of all Stage 9 download artifacts:
  - **BibTeX (`.bib`)**: Canonical active Working Collection bibliography for LaTeX and reference managers.
  - **RIS (`.ris`)**: Standard bibliographic interchange format compatible with EndNote, Zotero, Mendeley, and RefMan.
  - **XLSX Research Matrix (`.xlsx`)**: Multi-sheet workbook assembling Publications, Screening Decisions, Quality Assessment, Data Extraction, Synthesis Relations, and PRISMA Summary.
  - **CSV Extraction Dataset (`.csv`)**: Tabular structured extraction dataset with dynamic formula protection.
  - **JSON Extraction Dataset (`.json`)**: Machine-readable extraction read models for downstream analysis.
  - **PRISMA 2020 SVG (`.svg`)**: Standalone, deterministic vector diagram rendered using shared layout geometry.
  - **PRISMA 2020 PDF (`.pdf`)**: Standalone, printable PDF document embedding bundled DejaVu OFL Unicode fonts.

### Authoritative PRISMA 2020 Flow Architecture

- **Single Counting Path**: Single source of truth via `PrismaMetricsService` calculating stage transitions, deduplication subtotals, and exclusion breakdowns directly from persisted SQLite project state.
- **Presentation-Neutral Domain Model**: Pure `PrismaFlowModel` decoupling domain arithmetic from SVG and PDF renderers.
- **Width-Aware Metadata Fitting**: Deterministic width measurement and fitting using bundled DejaVu Sans Unicode font metrics for overlong titles (<= 820pt) and protocol versions (<= 550pt) in SVG and PDF, preventing viewport clipping and element overlap.

### Reviewer Isolation & Scope Integrity

- **Active Reviewer Propagation**: Reviewer-sensitive exports (XLSX, CSV, JSON, PRISMA SVG, PRISMA PDF) strictly isolate research records and screening/QA metrics to the active explicit reviewer.
- **Canonical Publications**: Superseded duplicate records are strictly excluded across all seven export formats.

### Security, Provenance & Auditability

- **Spreadsheet Formula Protection**: Automatic neutralization prefix (`'`) applied to leading `=`, `+`, `-`, `@`, `\t`, `\r` in CSV and XLSX cells and dynamic headers.
- **HTTP Provenance Headers**: `X-Project-Id`, `X-Protocol-Version`, `X-Application-Version`, and `X-Generated-At` response headers on all export endpoints.
- **In-File Provenance (D8)**: Trailing `%% Generated by SLR Platform ...` comment line in BibTeX and RIS exports.
- **Read-Only Safety**: All Stage 9 export endpoints are strictly GET-only and execute without mutating persisted SQLite state.

## Architecture and Guarantees

- Standard library SVG rendering with strict XML escaping (`xml.sax.saxutils.escape`).
- Pure PDF rendering via `fpdf2` with bundled DejaVu Sans fonts.
- Openpyxl multi-sheet workbook generation with hard 32,767 cell length truncation.
- Full UTF-8 support preserving Polish diacritics across all export serializers.
- No AI or LLM functionality in export pathways.
