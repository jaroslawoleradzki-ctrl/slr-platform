# SLR Platform v0.6.2 — Semantic Scholar Query Compatibility Fix

SLR Platform v0.6.2 is a focused hotfix for Semantic Scholar live search.

## Fixed

- Added provider-specific query rendering for Semantic Scholar's Graph API relevance search endpoint (`GET /graph/v1/paper/search`).
- Stopped sending unsupported common Boolean syntax, grouping, phrase quoting, and escaped query characters that caused HTTP 400 responses.
- Converts the canonical query tree to a best-effort plain-text query while retaining the exact physical `rendered_query` sent to Semantic Scholar.
- Reports non-lossless translation explicitly through the existing `is_lossless` and `warnings` fields; the platform does not claim Boolean equivalence where the endpoint cannot provide it.
- Added regression coverage for the reported query, single terms and phrases, AND/OR, nested grouping, special characters, provider metadata, and the exact HTTP request query parameter.

## Compatibility and scope

- OpenAlex and Crossref query rendering is unchanged.
- Public API schemas are unchanged.
- No database schema change or migration is required.
- No AI/LLM functionality is added.
