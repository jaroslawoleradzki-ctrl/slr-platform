# SLR Platform v0.4.6 — Data Extraction

## Highlights

### Phase 7 — Screening

- Configurable screening criteria.
- Title & Abstract and Full-Text screening workflows.
- Audit and progress reporting.
- Multi-reviewer conflict detection and adjudication.

### Phase 8 — Quality Assessment

- Project QA configuration and reviewer-scoped execution.
- Append-only assessment history.
- Lean Energy QA production template.

### Phase 9 — Data Extraction

- Configurable, project-scoped extraction domain and SQLite persistence.
- QA-aware eligibility with Full-Text and reviewer completion gates.
- Execution backend with server-side template validation.
- Append-only revisions, provenance, and reviewer attribution.
- Dynamic extraction GUI with table, matrix, and progress workflows.
- Lean Energy E1–E14 production template over the generic engine.
- E1 system-bound canonical publication metadata.
- Multiple Lean–EE relationships preserved as repeating items.
- Structured deterministic JSON and CSV dataset export.

## Architecture and guarantees

- Generic, domain-agnostic SLR platform architecture.
- Project isolation, reviewer attribution, and auditable history.
- SQLite persistence with read-only dataset export.
- No built-in AI or LLM functionality.
