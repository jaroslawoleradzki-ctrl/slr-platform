# SLR Platform v0.7.7 — Hotfix: disable caching of index.html

**Release date:** 2026-10-30
**Base version:** v0.7.6
**Breaking changes:** None
**Production deployment:** Performed (see `docs/reviews/V077_DEPLOYMENT_REPORT.md`).

## Summary

v0.7.7 is a hotfix for the root cause of "deploy changed nothing": browsers
heuristically cached `index.html` (via `ETag`/`Last-Modified`) and kept loading
a stale hashed bundle, even though the server served the new one. `index.html`
is now returned with `Cache-Control: no-cache, no-store, must-revalidate`.

No research data, PRISMA semantics, API shapes, or database schema changed.
No migrations.

## Change

- `app/api/main.py`: `FileResponse` for `index.html` (root and SPA fallback) now
  sets `Cache-Control: no-cache, no-store, must-revalidate`. Hashed assets under
  `/assets` remain cacheable.
